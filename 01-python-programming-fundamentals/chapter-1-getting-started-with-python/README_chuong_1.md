# Chương 1: Bắt đầu với Python (Getting Started with Python)

Chương này cung cấp những bước đầu tiên cần thiết để bắt đầu lập trình bằng Python. Chúng ta sẽ tìm hiểu những kiến thức cơ bản về Python, lý do ngôn ngữ này được sử dụng rộng rãi, đặc biệt trong các lĩnh vực như trí tuệ nhân tạo (Artificial Intelligence – AI) và phát triển web (Web Development), cũng như sự khác biệt giữa ngôn ngữ thông dịch (Interpreted Languages) và ngôn ngữ biên dịch (Compiled Languages).

Bạn sẽ học cách:

- Cài đặt Python trên các hệ điều hành Windows, macOS và Linux.
- Tương tác với trình thông dịch Python (Python Interpreter – REPL).
- Viết và thực thi tập lệnh Python đơn giản đầu tiên của bạn.
- Làm quen với các môi trường phát triển tích hợp (Integrated Development Environments – IDEs) và trình soạn thảo mã (Code Editors) phù hợp cho việc phát triển Python.

Khi hoàn thành chương này, bạn sẽ có một môi trường Python hoạt động đầy đủ và có kinh nghiệm chạy các đoạn mã Python cơ bản.
