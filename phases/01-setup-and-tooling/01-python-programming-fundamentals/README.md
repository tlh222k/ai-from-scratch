# Nền tảng Lập trình Python (Python Programming Fundamentals)

Bắt đầu hành trình lập trình của bạn với **Python**. Khóa học này cung cấp nền tảng vững chắc về các khái niệm cốt lõi, cú pháp và cấu trúc của Python. Học cách viết mã rõ ràng, hiệu quả thông qua các ví dụ thực tế và hướng dẫn từng bước, giúp bạn chuẩn bị cho những nhiệm vụ lập trình nâng cao hơn và phát triển trí tuệ nhân tạo (Artificial Intelligence – AI).

**Yêu cầu tiên quyết (Prerequisites):** Không yêu cầu kinh nghiệm lập trình trước đó.

**Trình độ (Level):** **Nhập môn (Introductory)**

- **Thiết lập môi trường Python (Python Environment Setup)**: Cài đặt và cấu hình môi trường phát triển Python trên hệ điều hành của bạn.

- **Các khái niệm lập trình cốt lõi (Core Programming Concepts)**: Hiểu và sử dụng biến (variables), kiểu dữ liệu (data types), toán tử (operators) và biểu thức (expressions).

- **Cấu trúc điều khiển (Control Structures)**: Triển khai logic điều kiện (`if/else`) và vòng lặp (`for/while`) để điều khiển quá trình thực thi chương trình.

- **Tổ chức dữ liệu (Data Organization)**: Làm việc với các cấu trúc dữ liệu cơ bản (data structures) như danh sách (lists), bộ giá trị (tuples), từ điển (dictionaries) và tập hợp (sets).

- **Khả năng tái sử dụng mã (Code Reusability)**: Định nghĩa và gọi hàm (functions) để tạo ra mã có tính mô-đun và dễ bảo trì.

- **Thao tác với tệp (File Operations)**: Thực hiện các thao tác nhập và xuất tệp (file input and output) cơ bản.

- **Tính mô-đun (Modularity)**: Hiểu cách sử dụng mô-đun (modules) và nhập các chức năng từ thư viện chuẩn của Python (Python standard library).

- **Lập trình hướng đối tượng cơ bản (Basic Object Orientation)**: Nắm bắt những ý tưởng nền tảng về lớp (classes) và đối tượng (objects).

- **Xử lý lỗi (Error Handling)**: Học cách dự đoán và quản lý lỗi bằng cơ chế xử lý ngoại lệ (exception handling).
