# Bắt đầu với PyTorch (Getting Started with PyTorch)

Tìm hiểu những kiến thức nền tảng về **PyTorch** để xây dựng và huấn luyện các mô hình học sâu (Deep Learning). Khóa học này bao gồm tensor, tính toán vi phân tự động, các mô-đun mạng nơ-ron, nạp dữ liệu và quy trình huấn luyện. Khóa học phù hợp với các nhà phát triển và kỹ sư đã có kiến thức cơ bản về Python và học máy (Machine Learning).

**Điều kiện tiên quyết (Prerequisites):** Có kiến thức cơ bản về Python và học máy (Machine Learning).

**Cấp độ (Level):** **Chuyên nghiệp (Professional)**

- **Thao tác với Tensor (Tensor Manipulation)**: Tạo, thao tác và thực hiện các phép toán trên tensor của PyTorch (PyTorch Tensors).

- **Tính toán vi phân tự động (Automatic Differentiation)**: Hiểu và áp dụng hệ thống Autograd của PyTorch để tính toán gradient (đạo hàm/độ dốc).

- **Xây dựng mạng nơ-ron (Neural Network Construction):** Xây dựng mạng nơ-ron bằng các mô-đun `torch.nn`, các lớp (layers) và hàm kích hoạt (activation functions).

- **Nạp dữ liệu (Data Loading):** Chuẩn bị và nạp dữ liệu một cách hiệu quả bằng Dataset và DataLoader của PyTorch.

- **Huấn luyện mô hình (Model Training):** Triển khai đầy đủ các vòng lặp huấn luyện và đánh giá cho mô hình học sâu (Deep Learning).

- **Lưu và khôi phục mô hình (Model Persistence):** Lưu và tải lại các mô hình PyTorch đã huấn luyện cùng các điểm lưu trạng thái (checkpoints).

- **Các kiến trúc cơ bản (Basic Architectures):** Xây dựng các mạng nơ-ron tích chập (Convolutional Neural Networks — CNNs) và mạng nơ-ron hồi tiếp (Recurrent Neural Networks — RNNs) đơn giản.
